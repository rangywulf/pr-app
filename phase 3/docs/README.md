# Shiver: PR Representative Tracking App

*Shiver by Kelpkin | Your PR team, swimming in sync.*

Shiver helps shop owners manage and track the social media activity of their public relations (PR) representatives. Reps promote a shop's products on social media and earn points that can be redeemed for cash, products, or store credit. Shiver gives the owner one place to manage their reps, review their posts, and track their points.

## Why I Built This

Manually tracking PR rep posts and points is a real bottleneck for small shop owners running a PR program, something I saw firsthand through my own experience running a planner sticker shop. This project started as an assignment for my Software Development program, but the problem it solves is one I understand from direct experience.

Shiver is built in phases, one per course, with each phase building on the last. The long-term goal is a Shopify app that small shop owners can install.
